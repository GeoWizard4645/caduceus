Control Caduceus from your phone

Caduceus is a Mac menu-bar app — there is no iPhone app yet. These are practical ways to message your Mac, run the same AI stack Caduceus uses (Hermes, Ollama), and trigger automation while you are away from the desk.

What you get remotely: ask questions, run agent / computer-use tasks on the Mac, kick off shell or Shortcuts workflows, and (with full remote desktop) use the Command Center UI itself. What stays on the Mac: clipboard history, dictation, and the floating staff — those need you at the keyboard unless you script equivalents.
Approach Typical cost Best for
Free — Tailscale + SSH + Hermes CLI $0 (Tailscale personal) Text-style commands from Termius or Prompt on iOS: SSH into your Mac and run hermes (same engine as Caduceus / and /c). Mac must be awake; enable Remote Login in System Settings.
Free — iOS Shortcuts + Tailscale SSH $0 One-tap phrases (“Summarize my inbox”, “Run backup”) as Shortcuts that SSH and run a script or hermes ask "…". Great for repeatable tasks; you build each Shortcut once.
Free — Telegram bot on your Mac (DIY) $0 (Telegram API) A small always-on bot process on the Mac forwards chat messages to Hermes or a shell script. You text from Telegram like a chat app. Requires basic scripting and keeping the Mac on.
Hermes messaging / channels Usually $0 for self-hosted; cloud models cost extra If your Hermes install exposes a messaging channel (see Hermes docs), your phone talks to the agent directly while Caduceus on the Mac stays in sync with the same config.
Pushover or Pushcut → Mac Shortcut Pushover ~$5 one-time; Pushcut subscription Send a notification from your phone that wakes a Shortcuts automation on the Mac (must be on the same Apple ID / network or use a webhook). Good for “run this on my Mac” buttons, not full chat.
Remote desktop (Jump, Screens, etc.) Paid app + optional Tailscale Full visual control — open Caduceus, use the palette, approve /c prompts yourself. Highest fidelity; uses more bandwidth and battery on the phone.

Example: free SSH from iPhone (Tailscale)

  1. Install Tailscale on Mac and iPhone (personal plan is free).
  2. On the Mac: System Settings → General → Sharing → enable Remote Login.
  3. On the phone: Termius → SSH to your Mac’s Tailscale IP → run Hermes or a script Caduceus would use.
